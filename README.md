# Glitch Busters Level 3: Decision Dungeon

**Week 3**: if/else, comparisons, indentation, and simple playing/won/lost game states.

## Deploy
Create a NEW GitHub repository named `glitch-busters-level-3` and upload the contents of this ZIP, preserving `game/` and `.github/workflows/` folders. In Settings > Pages select **GitHub Actions**. After deployment the URL should be `https://coxarcade.github.io/glitch-busters-level-3/`.

## Controls
Arrow keys/WASD: move; Z: sword; E: interact and hack boss; X: dash; C: bow (once discovered); B: bombs (once discovered); H: potion; V: Overdrive; J: journal; R: report.

**Code editor:** type the complete corrected Python snippet. Enter makes a new line; Tab inserts four spaces; Ctrl+Enter checks the repair. There is no automatic indentation. Backspace/Delete/Left/Right/Home/End edit the code. A wrong attempt displays an example, and students can retry with their previous code preserved.

The adventure begins with a sword; the bow and bombs are discovered later. Five unique written boss repairs per stage, five new decision-path puzzles, redesigned stage maps, tougher monsters, reworked secret rooms and relic gauntlets, and original dark ambient tracks.

**Testing:** Python source syntax checked; classroom browser and full playthrough still need verification. This game uses pygame/pygbag, not Pygame Zero, because it is the standalone Friday adventure.
